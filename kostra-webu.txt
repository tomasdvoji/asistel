================================================================
KOSTRA WEBU — šablona podle webů Asistel / Alerta
Statický firemní web s prodejnami, týmem, objednávkami a administrací
================================================================

TECHNOLOGIE
-----------
- Astro 4 (statický generátor, výstup = čisté HTML/CSS/JS, žádný server)
- Žádný framework navíc, žádná databáze
- Hosting: GitHub Pages (zdarma, automatický deploy přes GitHub Actions),
  připraveno i pro Cloudflare Workers (wrangler.jsonc) a Netlify
- Administrace obsahu: Decap CMS na /admin (přihlášení GitHub účtem,
  změny se commitují do repozitáře a web se sám přegeneruje)
- Odesílání e-mailů: EmailJS (přímo z prohlížeče, bez serveru;
  zdarma 200 e-mailů/měsíc)

KLÍČOVÉ FUNKCE
--------------
1) OBJEDNÁVKOVÝ FORMULÁŘ (objednat.astro)
   - výběr pobočky (předvyplnění přes ?prodejna=id), datum (min. dnešek),
     čas po půlhodinách, popis, jméno, telefon, e-mail
   - po odeslání přes EmailJS odejdou 2 e-maily (HTML šablony ve firemních
     barvách skládané v JS):
     a) POBOČCE — tabulka s údaji + tlačítko "Potvrdit termín"
        (odkaz na /potvrdit?d=<base64 payload s objednávkou>)
     b) ZÁKAZNÍKOVI — "rezervaci evidujeme", souhrn návštěvy
   - pobočka bez vlastního e-mailu → objednávka jde na centrální
     fallbackEmail z objednat.json
   - úspěch: souhrn + "Přidat do Google Kalendáře" + .ics ke stažení
   - chyba: hláška, formulář zůstává vyplněný (data se neztratí)
   - e-maily poboček nejsou v HTML přímo (base64) — ochrana před spam boty
   - všechny vstupy uživatele se v e-mailech escapují (XSS)

2) POTVRZENÍ OBJEDNÁVKY (potvrdit.astro)
   - zaměstnanec otevře odkaz z e-mailu, vidí souhrn objednávky
   - kliknutím odešle zákazníkovi finální potvrzení termínu (EmailJS)

3) FOTOGALERIE POBOČEK (prodejny.astro)
   - fotky se při buildu načtou ze public/prodejny/<id>/ (fs.readdirSync)
   - náhled = první fotka; když je na výšku, vezme se první na šířku
     (nebo se aspoň posune ořez níž, aby nebyl vidět jen strop)
   - lightbox: šipky u okrajů, počítadlo, ovládání klávesnicí (Esc/šipky),
     u jediné fotky se šipky ani odznak počtu nezobrazují

4) SVG MAPA ČR (index.astro)
   - viewBox 600x350, piny poboček z shops.json (mapX/mapY),
     klik na pin vede na kartu pobočky

5) ADMINISTRACE (/admin, Decap CMS)
   - config.yml mapuje všechny JSON soubory na formuláře
   - kolegové edituji texty, pobočky, tým i fotky bez znalosti kódu
   - každá změna = commit do GitHubu = automatický redeploy

DESIGN
------
- tmavý "spotlight" styl, akcentní barva magenta (#E20074, T-Mobile)
- fonty Inter + Outfit (Google Fonts)
- design tokeny (barvy, radiusy, stíny) v :root v styles.css
- reveal animace při scrollu (data-reveal), karty s hover efekty
- responzivní: hamburger menu, gridy se lámou na mobilu

CHECKLIST PŘI ZALOŽENÍ NOVÉHO PROJEKTU Z TÉTO KOSTRY
----------------------------------------------------
1. Zkopírovat repo, smazat public/prodejny, public/uploads, dist
2. Projít src/data/editable/*.json a nahradit obsah (název, IČO, adresa,
   pobočky, lidé, texty) — nic jiného se editovat nemusí
3. astro.config.mjs: nastavit base na název nového repa (GitHub Pages)
4. wrangler.jsonc: přejmenovat projekt
5. public/admin/config.yml: přepsat repo na nový GitHub repozitář
6. EmailJS: založit službu, vyplnit service/template/key v objednat.json,
   nastavit Allowed Origins na doménu webu (ochrana kvóty)
7. Grep na název staré firmy (case-insensitive) — musí být 0 výskytů
8. Fotky poboček do public/prodejny/<id>/1.jpeg, 2.jpeg…
9. npm install && npm run build — ověřit, pushnout, zapnout GitHub Pages
